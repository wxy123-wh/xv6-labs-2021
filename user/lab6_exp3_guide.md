# 实验三：页面置换算法对比（FIFO / LRU / OPTIMAL）

## 快速运行
- 编译：`cd /root/os-lab/xv6-labs-2021/user && gcc -std=c11 -Wall -Wextra -O2 lab6_exp3.c -o lab6_exp3`
- 运行：`./lab6_exp3`
- 默认序列 `{1,2,3,4,1,2,5,1,2,3,4,5}`，帧数 3/4/5，输出每种帧数下 FIFO、LRU、OPT 的缺页次数与缺页率。

## 代码核心思路
- 统一入口 `run_for_frames`：对给定帧数，分别调用三种算法，计算缺页次数和缺页率后汇总输出。
- **FIFO**：循环队列；命中跳过，未命中则缺页数+1，队列未满尾插，满时替换队头。
- **LRU**：`last_used` 记录每帧最近访问的时间戳；命中更新时间戳；未命中则挑时间戳最小（最久未用）的帧替换，若有空槽先用空槽。
- **OPTIMAL**：预知未来；未命中时扫描后续访问，挑未来最晚出现或不再出现的帧替换（空槽优先）。

## 输出如何看
- 每行对应一种帧数：`Frames=X | FIFO: a (r) | LRU: b (r) | OPT: c (r)`，其中 a/b/c 为缺页次数，r 为缺页率。
- 结尾提示可用来观察 Belady 异常（如 FIFO 在帧数增加时缺页反而可能增加）。

- 修改 `sequence` 或 `frame_options` 数组可测试不同访问模式或帧数。
- 若要看详细过程，可在各算法中插入打印语句跟踪帧内容与替换决策。
