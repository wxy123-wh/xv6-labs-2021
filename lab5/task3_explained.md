# 实验5·任务三：可视化与日志分析说明

本任务在任务二的基础上做“可视化/统计增强”，帮助你观察缓冲区状态和阻塞情况。

## 新增功能（都在 `lab5/producer_consumer.c` 内）
- **实时监控线程**：`monitor_thread` 每 0.5s 打印一次当前“缓冲区已有商品数/空槽数、已生产/已消费总数”，运行在后台，不影响主流程。
- **状态计数**：
  - `full_hits`：缓冲区达到“满”状态的次数。
  - `empty_hits`：缓冲区变成“空”状态的次数。
- **阻塞统计**：
  - 生产者在 `P(empty)` 上等待的总时间、事件次数，给出平均阻塞时长。
  - 消费者在 `P(full)` 上等待的总时间、事件次数，给出平均阻塞时长。
- **打印扩展**：`print_statistics()` 额外输出上述计数/阻塞信息，并打印 3 个信号量的状态。

> 仍然不改动 xv6 原始工程，只修改了 `lab5/producer_consumer.c`。

## 如何运行并观察
```bash
cd lab5
./producer_consumer   # 已在 Makefile 中
```
示例输出里会夹杂 `[MONITOR] ...` 行，表示实时状态。末尾的统计段会列出：
- 生产/消费总数是否匹配。
- `full_hits` / `empty_hits` 次数。
- 生产者/消费者平均阻塞时间（毫秒）。
- 信号量状态（value、等待次数）。

如果想把日志写入文件便于分析：
```bash
./producer_consumer > log.txt
```
可根据日志回答实验手册中的问题：满/空出现次数、阻塞时间、是否有死锁或数据不一致（统计已给出匹配结果）。***
